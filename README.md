# 🎬 UGC Remix Studio — Ultimate 3D Parkour Engine v9.3

Aplikasi otomatisasi berbasis **Streamlit** dan **Google Gemini API (`google-genai`)** untuk membedah, meremix, dan membuat prompt AI Video (Google Veo, Kling AI, Luma Dream Machine) khusus konten viral 3D Game / Parkour / Obstacle Challenge.

---

## 🌟 Fitur Utama v9.3

- **1:1 Roadmap Cloning & Multi-Action Density**: Membedah video referensi dan menghasilkan urutan aksi ganda per scene.
- **Dynamic 3D Map Arenas**: Pilihan 11 lokasi latar tempat unik (Maze Bank, Volcano Lava, Sky-High Cloud Ramp, dsb.).
- **Variasi Stand & Surface Objects**: Penyesuaian pijakan objek target (Yoga Fitness Balls, Ice Cubes, Oil Drums, dsb.).
- **Custom Climax Ending Actions**: Pilihan adegan klimaks penutup khusus (*Sacrifice Fall, Flying Knee, Kamikaze Drag*, dsb.).
- **Dynamic Scene Obstacles**: Penyesuaian rintangan ekstrem per-scene secara fleksibel.
- **Permanent Multi-Container Entities**: Objek/boneka target terpasang permanen sejak frame pertama (*zero pop-in*).
- **SEO & Metadata Center**: Otomasi pembuatan Judul viral (CTR tinggi), Deskripsi CTA, dan 18 Tags SEO global.
